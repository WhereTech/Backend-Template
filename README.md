# WhereTech ASP.NET Core Backend Template

WhereTech 通用 .NET 8 后端模板，可通过 `dotnet new` 自动替换解决方案、项目、目录和 Namespace 名称。

模板内置 ASP.NET Core Web API、EF Core、统一响应、事务、手机登录、Hangfire 定时清理，以及可选的文件存储和阿里云短信。

```bash
dotnet new install .
dotnet new wt-backend -n Acme.Order.Backend
```

模板用法见 [Docs](Docs/README.md)
